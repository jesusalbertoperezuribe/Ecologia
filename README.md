# EcoMarket 🌱

## Descripción del proyecto
**EcoMarket** es una tienda web enfocada exclusivamente en productos ecológicos, reutilizables y sustentables. Este proyecto fue maquetado aplicando las buenas prácticas vistas en clase:
- **HTML5 Semántico**: Uso apropiado de `header`, `nav`, `main`, `aside`, `section`, `article`, `footer`, evitando la "divitis".
- **CSS3 Puro**: Cero uso de JavaScript; toda la interactividad (favoritos, validaciones y animaciones) se resolvió con CSS.
- **Mobile First**: Diseño responsivo y fluido desde pantallas de 360px en adelante.
- **Metodología BEM**: Estructura limpia de selectores y modificadores.

## Tecnologías utilizadas
- HTML5 Semántico
- CSS3 Puro (Variables `:root`, Flexbox, CSS Grid)
- Pseudoclases (`:hover`, `:not()`, `:checked`, `:valid`, `:invalid`, `:focus-visible`)
- Animaciones CSS (`@keyframes`)

## Instrucciones de visualización
1. Clona o descarga este repositorio:
   ```bash
   git clone https://github.com/jesusalbertoperezuribe/Ecologia.git
   ```
2. Abre la carpeta del proyecto en **Visual Studio Code**.
3. Abre el archivo `index.html` en el navegador o ejecuta la extensión **Live Server**.
4. Puedes navegar libremente entre las 4 vistas del proyecto:
   - **Inicio (`index.html`)**
   - **Catálogo de Productos (`views/productos.html`)**
   - **Sobre Nosotros (`views/sobre-nosotros.html`)**
   - **Contacto (`views/contacto.html`)**
