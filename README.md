# EcoMarket 🌱

## Descripción del proyecto
**EcoMarket** es una tienda web de productos ecológicos, reutilizables y sustentables. Este proyecto fue maquetado aplicando el enfoque **Mobile First** y sin utilizar nada de JavaScript, resolviendo toda la interactividad (favoritos, validaciones y animaciones) únicamente con HTML5 y CSS3.

## Tecnologías utilizadas
- **HTML5 Semántico** (`header`, `nav`, `main`, `section`, `aside`, `article`, `footer`).
- **CSS3 Puro**:
  - Variables CSS (`:root`).
  - **Flexbox** y **CSS Grid** para el diseño responsivo.
  - Pseudoclases (`:hover`, `:checked`, `:valid`, `:invalid`).

## Instrucciones de visualización
1. Descarga o clona este repositorio.
2. Abre la carpeta en **Visual Studio Code**.
3. Abre el archivo `index.html` en tu navegador o con la extensión **Live Server**.
